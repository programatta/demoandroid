# Paso a paso para la construcción del proyecto.
Este documento describe el desarrollo de una pequeña demo implementada en Go con **Ebiten**, para la creación y adaptación en **Android**.

Cada paso incluye explicaciones técnicas, ejemplos de código, y una rama específica (`step-*`) en el repositorio para ver el estado del proyecto en ese momento.

|Paso|Descripcion|Rama|Ver|
|----|-----------|----|---|
|Introducción|Creación de la librería de android, creación del proyecto android con gradle y generación de apk de depuración y apk/aab de release|paso-01|[▶️](./step_01_es.md)|
|Demo con recursos empotrados|Demo que muestra recursos empotrados y adaptación a la ventana del dispositivo Android|paso-02|[▶️](./step_02_es.md)|
|Modo inmersivo y Splash screen|Se añade funcionalidad y configuración para establecer el modo inmersivo y un splash screen para evitar la pantalla en blanco mientras carga Go|paso-03-*|[▶️](./step_03_es.md)|

> 🔔 **Ramas con asterisco**
>
> Las ramas que llevan un asterisco (*) indican que tienen varios sub pasos.
